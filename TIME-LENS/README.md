# TIME LENS
Run: `npm install` then `npm run dev` → open http://localhost:5173 (museum) and /admin (dashboard).
Images: set in `src/data/initialData.js` (the `image` field). Use a Wikimedia/Unsplash URL, or put a file in
`public/images/` and write `/images/yourfile.jpg`. A missing image shows a bronze fallback automatically.
